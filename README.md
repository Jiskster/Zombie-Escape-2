# Zombie Escape 2

This is a work in progress SRB2 gametype.

It's a gametype inspired by a gamemode plugin from Counter Strike by the same name and the sequel to the original SRB2 Zombie Escape 1.


## Escape
***Like the gametype says!***
- Survivors win by reaching the goal.
- Zombies win by infecting all the survivors or reaching the goal before the survivors.
- Some maps have areas that hold everyone up for some time or even special gimmicks.

## Plague
***There is no escape...***
- Survivors win by surviving until the round ends.
    - Everyone starts with no items; they must find them scattered around the map.
- Zombies win by infecting all survivors.
    - Even survivors that die naturally without being infected become zombies.
- Fall damage is enabled, be careful of heights!
    - Zombies have 8 times the damage.
